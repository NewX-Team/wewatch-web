# WeWatch — Spatial Cinema & Creator Platform

## Fitur Utama

- **Status Ongoing / Project Ongoing (Warna Biru 🔵)**: Indikator status rilis serial/film yang sedang berlanjut minggu demi minggu bagi penonton dan kreator.
- **Verifikasi Kreator (Centang Biru 🔵)**: Akses fitur monetisasi, saldo pendapatan, dan lencana terverifikasi resmi oleh SuperAdmin.
- **Creator Studio Hub**: Manajemen episode mingguan, rilis film ongoing & completed, serta sinopsis karya.
- **SuperAdmin Control Console**: Manajemen pengguna, verifikasi akun kreator, dan pengawasan platform.
